# Nano Cheat Sheet

## Basic Commands

| Command | Description                                      |
|---------|--------------------------------------------------|
| `nano filename` | Open file in Nano editor                      |
| `Ctrl + O` | Save the file                                  |
| `Ctrl + X` | Exit Nano (prompts to save if needed)           |
| `Ctrl + R` | Open a file within Nano                        |
| `Ctrl + W` | Search for text within the file                |
| `Ctrl + \` | Find and replace text                          |
| `Ctrl + C` | Show current cursor position (line, column)    |
| `Ctrl + G` | Display help                                   |

## Navigation

| Command | Description                                      |
|---------|--------------------------------------------------|
| `Arrow Keys` | Move the cursor (up, down, left, right)        |
| `Ctrl + Y` | Scroll up one page                             |
| `Ctrl + V` | Scroll down one page                           |
| `Ctrl + A` | Move to the beginning of the line              |
| `Ctrl + E` | Move to the end of the line                    |
| `Ctrl + _` | Go to a specific line (requires line number)   |
| `Ctrl + U` | Move the cursor up one line                    |
| `Ctrl + D` | Move the cursor down one line                  |

## Text Manipulation

| Command | Description                                      |
|---------|--------------------------------------------------|
| `Ctrl + K` | Cut the current line or selected text            |
| `Ctrl + U` | Paste the cut text                              |
| `Ctrl + J` | Justify the current paragraph (align text)       |
| `Ctrl + T` | Check spelling (if enabled in Nano)              |
| `Ctrl + _` then `Ctrl + C` | Show the current cursor position  |
| `Ctrl + Shift + 6` | Set a mark (start selection)             |
| `Ctrl + K` then `Ctrl + U` | Copy text to clipboard           |

## File Handling

| Command | Description                                      |
|---------|--------------------------------------------------|
| `Ctrl + O` | Save the current file                           |
| `Ctrl + X` | Exit Nano (asks to save changes if needed)      |
| `Ctrl + R` | Read or open another file                      |
| `Ctrl + W` | Search for text                                |
| `Ctrl + \` | Find and replace text                          |
| `Ctrl + X` then `N` | Discard changes and exit            |

## Miscellaneous

| Command | Description                                      |
|---------|--------------------------------------------------|
| `Ctrl + Z` | Undo the last action                            |
| `Ctrl + Shift + 6` | Start selecting text (set mark)       |
| `Alt + A` | Select all text (use with `Ctrl + K` to cut)    |
| `Alt + D` | Delete the next character                       |
| `Alt + Backspace` | Delete the previous word              |
| `Alt + F` | Move forward one word                           |
| `Alt + B` | Move backward one word                          |
